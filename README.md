# Market Simulator

A step-by-step market simulator built from scratch in Python: a limit order book matching engine, agent-based market simulation, a backtester, and later machine learning.

## Roadmap
- [ ] Order book engine (limit and market orders, price-time priority)
- [ ] Agent-based market simulation
- [ ] Backtester (PnL, Sharpe ratio, max drawdown)
- [ ] ML: trading agent or short-term price model
- [ ] Comparison with real market data

## Status
Work in progress.
